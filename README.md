# MNIST CNN — early learning experiments

Early TensorFlow digit-classification notebooks, including a tf.data input pipeline and a subclassed CNN block.

## Notebooks

- [notebook1002c7fcf8.ipynb](notebooks/notebook1002c7fcf8.ipynb) — [original Kaggle notebook](https://www.kaggle.com/code/thorballer/notebook1002c7fcf8)
- [tutorial-8-subclassing.ipynb](notebooks/tutorial-8-subclassing.ipynb) — [original Kaggle notebook](https://www.kaggle.com/code/thorballer/tutorial-8-subclassing)

Early learning work; the subclassing notebook follows a tutorial. Both notebooks assume a GPU.

## Running

Open the original Kaggle notebook, attach its referenced data/models, choose the hardware expected by its setup cells, and run cells in order. Review install, login, and file-writing cells first.

For local use, install `requirements.txt` and adapt `/kaggle/input` paths. Dependencies are inferred from imports, not a tested lockfile; older APIs may need adjustment.
